Portfolio Project #1 — Multi-Page Website Layout
📌 About the Project
A modern, responsive, and cross-browser multi-page website layout built according to a design layout. Features structured HTML/SCSS code, UI components, and interactive features implemented with JavaScript.
Note: The WordPress / WooCommerce theme integration for this project is hosted in a separate repository.
🛠 Tech Stack
 HTML5 (Semantic multi-page markup)
 CSS3 / SCSS (BEM methodology, Flexbox & CSS Grid)
 JavaScript (Vanilla JS): DOM manipulation, interactive components, cart logic
 Build Tool: Gulp
 Version Control: Git & GitHub
